📖 How to generate a GitHub Personal Access Token (PAT)
  1. Log in to GitHub and click your profile picture → Settings.
  2. Scroll down on the left sidebar and select Developer Settings.
  3. Go to Personal access tokens → Select Tokens (classic).
  4. Click Generate new token (classic).
  5. Set a Note (e.g. "Claude Studio"), select expiration, and check the repo scope.
  6. Click Generate token and paste the token string below.
